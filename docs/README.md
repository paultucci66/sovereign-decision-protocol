# SDP Documentation

This directory contains explanatory material for the Sovereign Decision Protocol.

The RFCs define the protocol.

These documents explain the architecture, design principles, and supporting concepts.

## Documents

- [Architecture](architecture.md) — layers, boundaries, SDP vs DCP vs applications
- [Design Principles](design-principles.md) — principles guiding protocol design
- [Classification](classification.md) — classification and disclosure patterns

## Boundary

SDP is the protocol.

A Decision Control Plane is the product category.

Applications execute domain work.

Documentation should preserve that separation.
